Critérios

O que a nova casa tinha de garantir

① Grátis de verdade

Sem cartão internacional e sem plano que “expira” ao fim de 30 dias.

② MySQL preservado

O código usa mysql2, JSON, ENUM e chaves estrangeiras — trocar de SGBD seria caro.

③ Deploy automático

Ligar ao GitHub e publicar a cada push, sem copiar ficheiros à mão.

④ Segredos fora do chat

Senhas e tokens introduzidos apenas nos painéis; nunca no repositório nem na conversa.

⑤ Previsibilidade

Saber o que acontece quando a quota gratuita acaba: suspensão, estrangulamento ou cobrança.

⑥ Baixa manutenção

Sem servidor para gerir, sem TLS manual, sem scripts de arranque frágeis.

Decisão

Render + TiDB Cloud Starter

Une o deploy nativo por GitHub da Render com uma base MySQL-compatível que tem quota mensal clara e não cobra nada quando a esgota.

Porquê a Render

Web Service Node.js gratuito, healthcheck próprio, variáveis no painel e redeploy automático por push.

Porquê o TiDB

Aceita o driver mysql2 e o SQL do projeto; 5 GiB + 50 M RU por instância; sem cartão na primeira instância.

Compromisso assumido: a Render dorme após 15 minutos sem pedidos e o primeiro clique demora cerca de 1 minuto. Para a apresentação, basta abrir o link com antecipação.

Base de dados

Sem SQL Editor? Usamos mysql2

A interface do TiDB Starter não mostrava o editor de SQL. Criámos um script que liga com TLS e cria a base.

// backend/scripts/criar-base-tidb.js
mysql.createConnection({ host, port: 4000, user, password,
  database: 'freelamz', ssl: {} });
CREATE DATABASE IF NOT EXISTS freelamz
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
SHOW DATABASES; // freelamz confirmado na lista
A senha ficou só no backend/.env e nunca foi impressa. As mensagens de erro filtram a senha, substituindo-a por ***.

Incidentes

Dois erros reais, duas correcções

1. Missing user name prefix

O marcador <UTILIZADOR_TIDB> do ficheiro de exemplo ficou literal na MYSQL_URL.

Correcção: preencher com 4RvyEVJJGCtaatr.root no painel da Render.

2. ER_NO_SUCH_TABLE

O seed automático precisava da tabela categories, mas a base estava vazia.

Correcção: aplicar schema.sql + seed.sql + migrate.js por script.

Lição: o diagnóstico não estava no código — estava na configuração e na ordem das operações. O endpoint /api/health/db mostrou o utilizador errado sem revelar a senha.

Limites

O que o plano gratuito não dá

Cold start

15 min sem tráfego → serviço adormece; o próximo pedido demora cerca de 1 minuto.

Horas e banda

750 horas/mês por workspace; se esgotar, a Render suspende os serviços gratuitos.

Quota do TiDB

Ao esgotar 50 M RU, a instância é estrangulada até ao mês seguinte — sem cobrança.

Disco efémero

Imagens enviadas para uploads/ desaparecem no próximo deploy; é preciso armazenamento externo.

A documentação da Render desaconselha o plano gratuito para produção. Para uma demonstração académica é adequado — para um produto real, é preciso migrar para um plano pago.
